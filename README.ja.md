# Sweep

[繁體中文](README.md) · [简体中文](README.zh-Hans.md) · **日本語** · [English](README.en.md) · [Français](README.fr.md)

macOS と Windows のデスクトップに浮かぶ学習用カウントダウンタイマー。実物のダイヤル式タイマーがモデルです。
色付きの扇形がゼロに向かって縮んでいき、時間になると文字盤が点滅して知らせます。

![6 種類のカラーパターン](docs/colourways.png)

- すべてのウインドウの前面に浮かびます。macOS ではすべての Space（他アプリのフルスクリーンを含む）をまたぎますが、Windows には相当する仕組みがないため、開いた仮想デスクトップに留まります
- 2 つの外観：上部ボタン付きの本体表示と、邪魔にならないダイヤルのみ表示
- 実物のタイマーから起こした 6 種類のプリセットに加え、4 色を自由に組めるカスタムカラー
- ダイヤルをドラッグするか、分数（1–60）を直接入力して時間を設定
- 完了したカウントダウンは記録され、記録ウインドウでその日のリングと直近 30 日を確認できます
- 不透明度はカウントダウン中と待機中で別々に調整でき、マウスを重ねると必ず完全な不透明に戻ります
- ボタンにはカチッという手応え、リセットは払うような音、終了時には柔らかい一音
- 繁体字中国語・簡体字中国語・日本語・英語・フランス語に対応。初回起動時にシステムの言語から自動選択

## インストール

[Releases](../../releases) からダウンロードします:

| ファイル | 対象 |
|---|---|
| `Sweep-<バージョン>-arm64.dmg` | Mac、Apple Silicon |
| `Sweep-<バージョン>-x64.dmg` | Mac、Intel |
| `Sweep-<バージョン>-win-x64.exe` | Windows 10/11、64 ビット |

どちらのビルドも署名がないため、それぞれ一度だけ警告が出ます。

**macOS** — Sweep をアプリケーションフォルダにドラッグし、検疫属性を外します:

```sh
xattr -dr com.apple.quarantine "/Applications/Sweep.app"
```

**Windows** — SmartScreen が発行元不明として警告します。「**詳細情報**」→「**実行**」を選んでください。

## ソースから実行する

```sh
npm install
npm start
```

## 使い方

| 操作 | 方法 |
|---|---|
| 時間を設定 | 文字盤の内側をドラッグ——時計回りで増加、反時計回りで減少 |
| 数値で入力 | 文字盤をダブルクリックし、1–60 を入力して Enter |
| 開始 / 一時停止 | 中央のつまみ、または上部のバーボタンをクリック |
| リセット | 上部の丸いボタンをクリック。ダイヤルのみ表示では中央のつまみをダブルクリック |
| 移動 | 本体または文字盤の外周目盛りをドラッグ、あるいは ⌘／Ctrl を押しながらどこでもドラッグ |
| その他すべて | 右クリックメニュー：モード、サイズ、カラー、言語、記録、設定、終了 |

Dock にもタスクバーにも現れないアプリなので、終了は右クリックメニューから行ってください
（ウインドウがフォーカスされていれば ⌘Q／Ctrl+Q でも可）。

## ファイル構成

```
main.js              ウインドウ、前面表示の挙動、メニュー、保存、通知
preload.js           ページに window.api として公開される IPC ブリッジ
renderer/
  index.html         タイマー本体
  style.css          見た目。色はすべて 4 つの CSS 変数から決まります
  schemes.js         6 種類のプリセットと色のヘルパー（メインプロセスと共有）
  i18n.js            5 言語の辞書と DOM 翻訳器（メインプロセスと共有）
  dial.js            文字盤の幾何：目盛り、数字、扇形パス、ドラッグ角度の計算
  timer.js           カウントダウンの状態機械
  chime.js           終了音とボタン音。Web Audio でその場で合成
  app.js             配線：ドラッグ、当たり判定、描画、終了処理
  settings.html/js   設定ウインドウ
  history.html/js    記録ウインドウ
  panel.css          補助ウインドウ 2 つで共有するスタイル
tools/shot.js        開発用：ページを PNG に書き出して見た目を確認する
```

設定と記録は JSON ファイルです。macOS では `~/Library/Application Support/Sweep/`、Windows では `%APPDATA%\Sweep\` に置かれます。

## パッケージング

```sh
npm run dist        # macOS: 2 つの .dmg
npm run dist:win    # Windows: NSIS インストーラー
```

各プラットフォームのインストーラーはそのプラットフォーム上でしかビルドできません。
GitHub Actions が main への push ごとに両方を実行し、成果物はその実行の Artifacts に付きます。

いずれも未署名です。macOS の公証には有料の Apple Developer ID が、
Windows で SmartScreen の警告を消すにはコード署名証明書が必要です。
